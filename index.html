👋 Welcome to HOC OES
The Operations Engagement System connects every team to live production data. Pick where to start based on your role:
👥 SHIFT LEADS / SUPERVISORS
Start with Employee Roll Call — take attendance, track points
📤 PLANNERS / SCHEDULERS
Start with Data Upload Hub — drop your Excel files, refresh everything
🧪 COMPOUND TEAM
Start with Compound Coordinator — see what's overdue, mark batches complete
⚙️ PRODUCTION FLOOR
Start with Production Supervisor — live status by line, OEE, downtime
🔬 QC TEAM
Start with Quality Lab — pending tests, release decisions, holds
📊 LEADERSHIP
Start with Control Tower — KPIs, risks, pipeline flow, all in one
📚 NEED THE FULL TRAINING?
The Onboarding & Operations Guide has step-by-step walkthroughs for every role, a glossary, KPI definitions, troubleshooting, and a knowledge check quiz. ~15 min to go through.
💡 KEY THINGS TO KNOW
  • Click any KPI number or row — it'll jump you to the right tool to act on it
  • Data flows downstream — Compound → PreWeigh → QC → Production → FG → Warehouse
  • Yellow banner means data is stale (over 7 days); re-upload from Data Upload Hub
  • System Diagnostics (top right card) shows health of every connection
  • Tablet? Add to home screen — works offline once cached

How to use HOC-OES correctly
Click any tool above to open it directly. Each tool has a ← HOC-OES button to return here.
All tools share the sync bus automatically — updates from Pre-Weigh appear in Compound Scheduler, Leadership Tower, and everywhere else.

For full sync across multiple devices: host this folder on SharePoint or run python -m http.server 8000 in the folder, then open http://localhost:8000/index.html.
